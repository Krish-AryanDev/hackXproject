## The Aesthetics of Spatial Layout

FutureHire focuses on a carefully crafted spatial environment. By utilizing deep dark themes (`#0A0A0A` background) and subtle emerald accents (`#10B981`), it creates a focused, distraction-free zone that mirrors high-end native desktop environments[cite: 1]. 

## Core Features

<details>
<summary><b>Interactive Code Canvas</b></summary>
<br>

* **Real-time Syntax Highlighting:** A custom, lightweight regex-based tokenizer that renders C++17 syntax with accessible colors without heavy external libraries[cite: 1].
* **History Evolution Drawer:** View previous code snapshots and restore them instantly[cite: 1].
* **Thinking Checkpoint:** A collapsible markdown reasoning panel to document time/space complexity trade-offs prior to submission[cite: 1].
</details>

<details>
<summary><b>Fluid Window Management</b></summary>
<br>

* **Draggable Panes:** Fully resizable spatial layouts. Adjust the problem description, code editor, and console output dynamically using vertical and horizontal resize handles[cite: 1].
* **Smart Bounds:** Resizers are mathematically constrained to prevent layout collapse, ensuring the IDE remains functional at all times[cite: 1].
</details>

<details>
<summary><b>Developer Ergonomics</b></summary>
<br>

* **Command Palette:** Press `Cmd/Ctrl + K` to open a centralized modal for rapid action execution, including running code, saving, submitting, and accessing settings[cite: 1].
* **Subtle Telemetry:** Animated connection indicators and non-intrusive monospace timers maintain awareness without causing distraction[cite: 1].
* **Granular Settings:** Adjust font sizes (12px - 15px) and tab preferences directly within the interface[cite: 1].
</details>

## Native Keyboard Shortcuts

FutureHire is optimized for power users and keyboard-driven workflows.

| Command | Action | Description |
| :--- | :--- | :--- |
| <kbd>⌘</kbd> + <kbd>K</kbd> | **Command Palette** | Open the master command search[cite: 1]. |
| <kbd>⌘</kbd> + <kbd>↵</kbd> | **Run Code** | Execute the current code against the test suite[cite: 1]. |
| <kbd>⌘</kbd> + <kbd>S</kbd> | **Save Solution** | Trigger an explicit save action[cite: 1]. |

## Architecture & Routing

This project achieves a complete multi-view application within a single file (`code.html`)[cite: 1]. It utilizes a custom, lightweight client-side router to transition seamlessly between:

1. **`/candidate`** - The active evaluations dashboard[cite: 1].
2. **`/candidate/assessment/demo`** - The primary IDE workspace[cite: 1].
3. **`/candidate/submitted`** - The final success telemetry screen[cite: 1].

## Getting Started

FutureHire is completely zero-dependency and relies entirely on CDN-delivered Tailwind CSS and Vanilla JavaScript[cite: 1]. 

1. Clone or download the repository.
2. Open `code.html`[cite: 1] directly in any modern web browser.
3. No build steps, package managers, or configuration files are required.
